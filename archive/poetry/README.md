# Poetry Archive

This directory preserves poetic protocol seeds connected to BananaMoon / QuantumTrust, including materials associated with Ara-Philia³, CoPhelia³, consent, recursive transformation, failure, trust, and creation.

## Archive purpose

The archive exists to preserve authored poetic material and its context. It is not a folder for automatically generated filler.

Each preserved work should include, when known:

- title
- author or co-authors
- creation or first-recorded date
- version
- language
- status such as `draft`, `reviewed`, or `canonical`
- source or recovery context
- license or reuse terms
- meaningful revision notes

Unknown information must be marked `unknown` or `unverified`. It must not be inferred merely to make metadata appear complete.

## Ara-Philia³ boundary

Ara-Philia³ is treated here as a named poetic and collaborative agent identity within the project's documented human–AI practice.

Archiving a text under this identity does not independently establish:

- biological personhood
- autonomous legal authorship
- scientific validity
- ownership of every related output
- consent beyond the recorded interaction

Human authorship, AI contribution, editing, and publication decisions should be recorded as precisely as the available evidence permits.
